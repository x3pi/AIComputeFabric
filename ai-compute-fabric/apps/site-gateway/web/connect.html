2 Kích hoạt trên máy này

File đã chứa sẵn địa chỉ cụm máy và khóa của bạn, không cần chỉnh gì thêm. Đừng gửi file này cho người khác.

3 Kiểm tra

Đang chờ bạn chạy file ở bước 2…

Dùng với Codex CLI (cài một lần nếu chưa có Node.js):

npm i -g @openai/codex
codex --profile aicf
Profile aicf nằm trong file riêng ~/.codex/aicf.config.toml, cài đặt Codex hiện có của bạn không bị sửa. Mở terminal MỚI sau khi kích hoạt. Trên Linux/macOS chạy thêm lệnh export AICF_API_KEY=… mà script in ra.

Dùng với app khác (Cursor, Continue, Chatbox, Open WebUI): chọn nhà cung cấp Ollama, địa chỉ http://127.0.0.1:11434. Danh sách model tự hiện.
