Đặc tả Decorator & Lớp trong gói aicf

            

              

                
                  

                    API / Decorator
                    Tham số Hỗ trợ
                    Mô tả Hành vi Chuẩn Cloud
                  

                
                
                  

                    @aicf.endpoint(...)
(Chuẩn Beam/Beta9)		
                    name="...", gpu="any", vram_mb=1024, memory=512, keep_warm_seconds=120, image=..., volumes=[...]
                    Tương thích 1:1 với beam-cloud/beta9: xuất hàm thành REST JSON Endpoint tại POST /api/serverless/v1/web/{tenant}/{app}/{fn}, hỗ trợ cả chữ ký def fn(**inputs) và def fn(payload: dict).
                  

                  

                    @aicf.task_queue(...)
(Chuẩn Beam/Beta9)		
                    name="...", gpu="any", vram_mb=2048, retries=2, keep_warm_seconds=60
                    Hàng đợi Background Job bất đồng bộ: gọi job = fn.put(...) (hoặc fn.spawn(...)) → nhận FunctionCall để tra cứu trạng thái job.get(), xem log job.logs() hoặc hủy job.cancel().
                  

                  

                    aicf.Sandbox(...)
(Chuẩn Beam/Beta9 & Modal)		
                    gpu="any", vram_mb=1024, memory=512, keep_warm_seconds=120
                    Khởi tạo môi trường Sandbox cô lập (sb = Sandbox(...).create()): chạy code động sb.run_code("..."), chạy lệnh shell sb.process.exec("...") và thu hồi ngay bằng sb.terminate().
                  

                  

                    @app.function(...)
(Chuẩn Modal.com)		
                    gpu=None|"any"|"RTX3060", vram_mb=0, memory_mb=512, cpus=1.0, timeout_s=30, keep_warm_s=60, retries=0, image=..., secrets=[...], volumes={...}
                    Đóng gói hàm Python qua cloudpickle, cấp phát container cô lập (và GPU Lease nếu vram_mb > 0). Hỗ trợ .remote(), .local(), .map(), .starmap(), .spawn(), .put().
                  

                  

                    @app.cls(...)
@aicf.enter()
@aicf.exit()		
                    Giống @app.function
                    Khởi tạo đối tượng một lần duy nhất khi container khởi động (@aicf.enter() nạp trọng số model vào VRAM) và tái sử dụng qua hàng nghìn lượt gọi ấm mà không phải nạp lại model.
                  

                  

                    @app.web_endpoint()
                    method="POST", requires_auth=True, cors_origins=[]
                    Xuất hàm đã triển khai thành REST JSON Endpoint tại POST /api/serverless/v1/web/{tenant}/{app}/{fn} (chỉ nhận/trả JSON an toàn, không nhận pickle từ Internet).
                  

                  

                    aicf.Image.debian_slim()
                    .pip_install("pkg==ver").env({...}).add_local_python_source("pkg")
                    Định nghĩa môi trường bất biến theo mã băm env_hash; chỉ chấp nhận wheel có kiểm tra hash qua uv trong builder container tách biệt.
                  

                  

                    aicf.Volume.from_name(name)
                    .put(path, bytes), .get(path), .ls(), .rm(path)
                    Lưu trữ tệp bền vững theo từng Tenant; khi gắn vào hàm qua volumes={"/data": vol}, container có thể đọc/ghi trực tiếp tại /mnt/volumes/{name}.
                  

                  

                    import aicf_gpu
(CUDA / PTX Runtime)		
                    .device_info(), .matmul(A, B), .saxpy(a, x, y), .cosine_search(q, docs), .vram_stress(alloc_mib)
                    Mô-đun GPU tích hợp sẵn trong mọi container: gọi trực tiếp libcuda.so.1 (CUDA Driver API) để cấp phát VRAM (cuMemAlloc_v2) và chạy PTX Kernel trên GPU NVIDIA mà không cần tải image nặng.
                  

                
              

            

          


          
          

            
Bảng Tham chiếu HTTP REST API (Qua Cổng site-gateway :18080)

            
Mọi request từ người dùng đều gửi kèm Header: Authorization: Bearer <AICF_API_KEY_OR_SESSION>.

            

              

                
                  

                    Phương thức & Đường dẫn
                    Quyền yêu cầu
                    Mô tả & Payload
                  

                
                
                  

                    POST /api/serverless/v1/auth/register
                    Công khai / Cloud IAM
                    Đăng ký Tài khoản Cloud mới: {"name": "team-ai", "email": "dev@aicf.local", "password": "..."} → trả về api_key (CLI) và session_token (Web).
                  

                  

                    POST /api/serverless/v1/auth/login
                    Công khai / Cloud IAM
                    Đăng nhập bằng {"identifier": "dev@aicf.local", "password": "..."} hoặc {"api_key": "aicf_..."} → cấp phiên aicf_sess_....
                  

                  

                    POST /api/serverless/v1/auth/logout
                    Session / Tenant Key
                    Đăng xuất và thu hồi ngay phiên aicf_sess_... trên máy chủ mà không làm mất hiệu lực Khóa API CLI của Tenant.
                  

                  

                    POST /api/serverless/v1/auth/rotate-key
                    Session / Tenant Key
                    Cấp lại Khóa API aicf_... mới cho Workspace và vô hiệu hóa khóa cũ ngay lập tức.
                  

                  

                    POST /api/serverless/v1/signup
                    Công khai / Self-Serve
                    Đăng ký nhanh Workspace Developer 1-Click: {"name": "my-team"} → trả về {"tenant": {...}, "api_key": "aicf_..."}.
                  

                  

                    POST /api/serverless/v1/deploy
                    Tenant API Key
                    Triển khai ứng dụng (hỗ trợ cả source_code + entrypoint từ Web IDE hoặc bundle_b64 từ SDK) → trả về active_version: "v-...".
                  

                  

                    POST /api/serverless/v1/apps/{app}/rollback
                    Tenant API Key
                    Chuyển active_version về phiên bản liền trước (hoặc {"version": "v-..."}) trong < 10 ms mà không làm đứt kết nối đang chạy.
                  

                  

                    POST /api/serverless/v1/web/{tenant}/{app}/{fn}
                    Tenant API Key
                    Gọi hàm Web Endpoint bằng JSON thuần (Content-Type: application/json).
                  

                  

                    POST /api/serverless/v1/invoke
                    Tenant API Key
                    Gọi đồng bộ hàm Serverless; tự động cấp phát GPU Lease và giữ ấm container theo keep_warm_s.
                  

                  

                    POST /api/serverless/v1/spawn
                    Tenant API Key
                    Gọi bất đồng bộ ở nền → trả về 202 Accepted {"call_id": "..."}. Tra cứu qua GET /v1/calls/{id} hoặc SSE GET /v1/calls/{id}/logs.
                  

                  

                    PUT / GET / DELETE /api/serverless/v1/volumes/{vol}/{path}
                    Tenant API Key
                    Tải lên, tải xuống (kèm kiểm tra X-Aicf-Sha256) hoặc xóa tệp trong Volume của Tenant.
                  

                
              

            


            
Bảng Mã lỗi Chuẩn (Standard Cloud Error Codes)

            

              

                
                  

                    HTTP Status
                    Mã lỗi (error.code)
                    Nguyên nhân & Cách xử lý
                  

                
                
                  

                    400 Bad Request
                    syntax_error / entrypoint_not_found
                    Mã nguồn Python bị lỗi cú pháp (báo rõ số dòng) hoặc thiếu hàm entrypoint đã khai báo.
                  

                  

                    401 Unauthorized
                    unauthorized
                    Thiếu hoặc sai Authorization: Bearer aicf_....
                  

                  

                    403 Forbidden
                    serverless_disabled / gpu_denied
                    Tenant chưa được bật quyền Serverless hoặc yêu cầu GPU khi hạn mức gpu_allowed=false.
                  

                  

                    429 Too Many Requests
                    concurrency_exceeded
                    Vượt quá số hàm chạy đồng thời tối đa (max_concurrency) của Workspace.
                  

                  

                    503 Service Unavailable
                    no_capacity / serverless_draining
                    GPU đang ưu tiên bảo vệ VRAM cho người dùng máy trạm hoặc LLM chính (G-VRAM / G-RECLAIM); thử lại sau Retry-After giây.
                  

                
              

            

          


          
          

            
Tham chiếu Lệnh CLI (aicf)

            
aicf run my_app.py                         # Thực thi hàm cục bộ/trên cụm từ tệp Python
aicf deploy my_app.py                      # Đóng gói & triển khai phiên bản bất biến lên Cloud
aicf app list                              # Liệt kê các ứng dụng & phiên bản của Workspace
aicf app rollback text-analyzer            # Rollback ứng dụng về phiên bản ổn định liền trước
aicf app stop text-analyzer                # Gỡ ứng dụng & giải phóng toàn bộ container liên quan
aicf container list                        # Xem danh sách container đang giữ ấm của bạn
aicf container stop <container_id>         # Giải phóng container ấm ngay lập tức
aicf volume put shared-artifacts a.json ./a.json  # Tải tệp lên Volume kèm kiểm tra SHA-256
aicf volume ls shared-artifacts            # Liệt kê tệp trong Volume
aicf secret set my-openai-secret OPENAI_API_KEY=sk-... # Lưu biến bí mật cho container
